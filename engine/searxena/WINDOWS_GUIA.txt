================================================================================
                         SEARXENA EN WINDOWS
                 GUÍA DE INSTALACIÓN, USO Y CONFIGURACIÓN
================================================================================

searXena es una aplicación independiente para metabúsqueda local. Está
implementada con Python, FastAPI, Uvicorn y motores propios en
core\engines. Su desarrollo comenzó como un intento experimental de portar
ideas de SearXNG a Windows, pero actualmente searXena no ejecuta SearXNG ni
depende de su código, sus scripts o su infraestructura.

Esta guía describe únicamente el proyecto searXena.

================================================================================
REQUISITOS
================================================================================

- Windows 10 u 11
- Python 3.10 o posterior
- PowerShell
- Git (solo si se instala clonando el repositorio)
- Conexión a Internet para consultar los motores externos

Las dependencias Python se instalan desde requirements.txt.

================================================================================
INSTALACIÓN RÁPIDA DESDE EL REPOSITORIO
================================================================================

1. Clonar el repositorio y entrar en su raíz:

    git clone https://github.com/NeuralArchLabs/searXena.git
    cd searXena

2. Si PowerShell bloquea scripts, permitir scripts locales para el usuario:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

3. Ejecutar el instalador incluido:

    .\win_setup.ps1

El instalador crea el entorno virtual en local\py3 y utiliza
requirements.txt para instalar las dependencias.

================================================================================
INICIAR SEARXENA
================================================================================

Ejecutar desde la raíz del repositorio:

    .\run.ps1

El lanzador abre el navegador e inicia la aplicación en:

    http://127.0.0.1:8000

Para detenerla, volver a la ventana de PowerShell y pulsar Ctrl+C.

El puerto está definido actualmente en core\app.py. Si el puerto 8000 está
ocupado, debe liberarse antes de iniciar la aplicación o cambiarse el
entrypoint de forma explícita.

================================================================================
INSTALACIÓN MANUAL
================================================================================

Desde la raíz del repositorio:

    python -m venv local\py3
    .\local\py3\Scripts\python.exe -m pip install -U pip wheel setuptools
    .\local\py3\Scripts\python.exe -m pip install -r requirements.txt
    .\local\py3\Scripts\python.exe core\app.py

También es posible activar el entorno antes de instalar o ejecutar:

    .\local\py3\Scripts\Activate.ps1
    python -m pip install -r requirements.txt
    python core\app.py

================================================================================
CONFIGURACIÓN
================================================================================

La configuración principal está en:

    core\settings.json

La plantilla de referencia está en:

    core\settings.example.json

La sección general controla, entre otros valores:

- instance_name
- safe_search
- default_lang
- timeout
- cache_ttl

La sección engines habilita o deshabilita motores y define su peso. Los
cambios de configuración se aplican al reiniciar el proceso.

El timeout controla cuánto espera el orquestador a los motores. Los motores
que no respondan dentro del plazo pueden fallar individualmente; las
respuestas que sí hayan llegado se conservan.

================================================================================
USO WEB
================================================================================

- /                  Interfaz principal
- /search            Búsqueda web HTML (GET o POST)
- /settings          Preferencias de la instancia
- /extract?url=...   Modo lectura para una URL
- /proxify?url=...   Proxy interno de recursos remotos
- /robots.txt        Robots de la instancia
- /ai.txt            Información para agentes

Categorías disponibles en la interfaz y en la API:

    general, images, videos, news, maps, shopping

================================================================================
API JSON
================================================================================

Búsqueda estructurada:

    POST http://127.0.0.1:8000/api/v1/search

Ejemplo desde PowerShell:

    $body = @{
        query = "python fastapi"
        category = "general"
        pageno = 1
        language = "es"
        limit = 10
    } | ConvertTo-Json

    Invoke-RestMethod `
        -Method Post `
        -Uri http://127.0.0.1:8000/api/v1/search `
        -ContentType "application/json" `
        -Body $body

Otros endpoints:

    GET  /api/v1/tools_schema
    POST /api/v1/extract

El resultado de búsqueda incluye results y meta. meta.has_more indica si
existen resultados adicionales más allá del límite solicitado.

================================================================================
COMPROBACIÓN RÁPIDA
================================================================================

Con la aplicación iniciada:

    Invoke-WebRequest http://127.0.0.1:8000/

Para comprobar la API:

    Invoke-RestMethod `
        -Method Post `
        -Uri http://127.0.0.1:8000/api/v1/search `
        -ContentType "application/json" `
        -Body '{"query":"nintendo switch","category":"general","limit":5}'

================================================================================
PROBLEMAS COMUNES
================================================================================

"Scripts are disabled on this system"

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

"Python no encontrado"

- Instalar Python desde https://www.python.org/downloads/
- Abrir una nueva ventana de PowerShell.
- Comprobar:

    python --version

"No se encuentra local\py3"

    .\win_setup.ps1

"ModuleNotFoundError"

    .\local\py3\Scripts\python.exe -m pip install -r requirements.txt

"El puerto 8000 está ocupado"

    Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue

Cerrar únicamente el proceso que corresponda a la instancia de searXena o
iniciar la aplicación después de liberar el puerto.

"No aparecen resultados de un motor"

Los motores consultan servicios externos y pueden sufrir bloqueos,
CAPTCHAs, cambios de HTML, problemas de DNS o fallos de red. Revisar la
salida de la consola y probar nuevamente antes de modificar la aplicación.
Un fallo individual no implica que searXena dependa de SearXNG.

================================================================================
ESTRUCTURA REAL DEL PROYECTO
================================================================================

core\app.py              Aplicación FastAPI y rutas HTTP
core\engine_manager.py   Orquestación, caché y ranking
core\engines\            Adaptadores de motores de búsqueda
core\templates\          Plantillas HTML
core\static\             CSS, JavaScript y recursos estáticos
core\ozen_engine\        Motor de extracción O-ZEN
core\settings.json       Configuración de la instancia
requirements.txt           Dependencias Python
win_setup.ps1              Instalador para Windows
run.ps1                    Lanzador de la aplicación

================================================================================
DESARROLLO Y CAMBIOS
================================================================================

Ejecutar siempre los scripts desde la raíz del repositorio. Después de
cambiar Python o requirements.txt, reinstalar las dependencias en local\py3.
Después de cambiar core\settings.json, reiniciar searXena.

Para revisar errores de ejecución, conservar la salida de la consola del
proceso. Las consultas dependen de la disponibilidad y políticas de los
motores externos.

LICENCIA Y CRÉDITOS
================================================================================
